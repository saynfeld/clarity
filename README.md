# Clarity — support & privacy site

Static pages served via GitHub Pages, used for the two URLs App Store Connect
requires:

| App Store Connect field | Page |
|---|---|
| Support URL | `index.html` |
| Privacy Policy URL | `privacy.html` |

Both pages are bilingual (English + Russian) and follow the system light/dark theme.

The privacy policy is generated from `../privacy-policy.html` — edit that file and
regenerate, or edit `privacy.html` directly and keep the two in sync.
